# Project Statement

## Project Title

Banking and Account Management System

---

## 1. Problem Statement

Managing basic banking operations manually can be time-consuming and may lead to errors in maintaining customer, account, and transaction records.

This project aims to develop a console-based Banking and Account Management System using Java that simulates essential banking operations such as customer management, account creation, deposits, withdrawals, money transfers, balance inquiry, and transaction history.

The system also provides an admin module for managing and viewing customer, account, and transaction information.

---

## 2. Project Scope

The scope of this project includes:

- Customer profile creation and management.
- Creation of Savings and Current accounts.
- Account balance management.
- Deposit and withdrawal operations.
- Transfer of money between accounts.
- Transaction history management.
- Customer authentication.
- Admin authentication and management operations.
- Input validation and exception handling.
- File-based data persistence.

The project is designed as an academic simulation and does not connect to any real banking system or financial institution.

---

## 3. Target Users

### Customers

Customers can use the system to:

- Create their profile.
- Access their account.
- Check account balance.
- Deposit money.
- Withdraw money.
- Transfer money.
- View transaction history.
- Update profile information.
- Close an account.

### Bank Admin

The admin can use the system to:

- View all accounts.
- Search accounts.
- Search customers.
- View account details.
- View transaction records.

---

## 4. High-Level Features

The major features of the system are:

1. Customer Management
2. Account Management
3. Banking Transactions
4. Transaction History
5. Customer Authentication
6. Admin Management
7. Input Validation
8. Exception Handling
9. File-Based Data Storage

---

## 5. Account Types

The system supports two types of bank accounts:

### Savings Account

A Savings Account requires a minimum balance of ₹500.

### Current Account

A Current Account supports an overdraft limit of ₹5,000.

---

## 6. Expected Outcome

The expected outcome is a functional Java-based console application that demonstrates the implementation of a basic banking management workflow using object-oriented programming, modular design, exception handling, validation, collections, and file handling.
